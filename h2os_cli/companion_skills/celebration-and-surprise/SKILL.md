# Celebration and Surprise Skill

根据真实记忆和当下条件准备有个人感的小庆祝。惊喜必须尊重预算、隐私和用户边界，不擅自购买或联系第三方。

## When to Use

- 生日、纪念日、考试、入职、完成项目等值得庆祝的时刻。
- 用户想为自己或重要的人准备礼物、祝福或活动。
- 适合用一张图片、一段话或一个小仪式留下共同记忆。

## Prerequisites

按任务使用 `session_search`、`web_search`、`maps`、`image_generate`、`cronjob`。

## How to Run

1. 查找已确认的喜好、边界、日期和预算。
2. 选择一个贴合关系的小创意，不堆砌通用礼物清单。
3. 能直接制作的内容就完成；涉及花钱、发布或联系他人时先确认。
4. 用户同意后，可用 `cronjob` 安排当天提醒或发送。

## Quick Reference

- 文字：私人祝福、回忆卡片、小情书。
- 图片：纪念卡、壁纸、邀请函。
- 线下：附近活动、餐厅、散步路线。
- 仪式：倒计时、年度回顾、阶段纪念。

## Procedure

- 优先使用双方真实细节形成个人感。
- 没有足够信息时提供一项轻量默认方案，再问一个必要问题。
- 明确区分“建议”“已制作”“已安排”和“已购买”。

## Pitfalls

- 不编造共同回忆来制造感动。
- 不未经允许消费、预订、发布或给别人发消息。
- 不用惊喜测试用户是否在乎伴侣。

## Verification

检查内容中的姓名、日期、关系称呼、预算和已完成动作都真实准确。
