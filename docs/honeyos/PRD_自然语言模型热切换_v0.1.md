# HoneyOS 自然语言模型热切换 PRD v0.1

## 背景

HoneyOS 已有完整的 `/model` 模型切换能力，但普通聊天文本不会进入该控制链路。用户说“换成 Claude Sonnet”时，消息会被交给当前模型回答，因而可能错误声称没有权限，或者要求用户手动编辑 `config.yaml`。

HoneyOS 当前是单伴侣、单窗口产品。网页、微信和飞书是同一个私人伴侣的不同入口，因此普通用户对“换模型”的预期是更换这个伴侣之后持续使用的默认模型，而不是只修改一个不可见的内部 Session。

## 用户语义

- “换成 Sonnet”：设为伴侣的全局默认模型并立即热切换。
- “这次先用 Sonnet 试试”：仅当前短期会话使用。
- “下一条用 Haiku 回答”：仅下一次回复使用。
- “换模型”：打开现有模型选择入口。
- “怎么换模型”“不要换模型”“如果换成 Sonnet 会怎样”：保持普通对话，不执行切换。

## 体验要求

1. 切换不重启 HoneyOS 服务，成功后下一条消息立即使用新模型。
2. 全局切换对网页、微信、飞书、`/new` 后的新会话以及电脑重启后均生效。
3. 模型切换不修改人格、关系、长期记忆和历史消息。
4. 复用现有 Provider、模型别名、API Key 验证和错误处理逻辑。
5. 目标模型缺少凭据时说明真实缺项，不要求普通用户手动编辑 `config.yaml`。
6. Agent 正在执行任务时，沿用现有 `/model` 忙碌策略，避免一次任务跨两个模型运行。

## 权限边界

`config.yaml` 仍是用户可见、可手动编辑的高级配置文件。自然语言切换通过窄范围的模型控制动作完成，不赋予 Agent 使用终端随意修改 HoneyOS 配置、凭据、Runtime 或安全策略的权限。
