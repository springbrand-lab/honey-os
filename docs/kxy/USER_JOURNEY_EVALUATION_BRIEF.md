# HoneyOS 1.6 用户旅程实验报告（精简版）

- 测试环境：macOS、Conda Python 3.12.13、OpenRouter
- 统计原则：只保留通过项和重大问题；轻微延迟、措辞偏差、非关键遗漏均忽略。

| Case | 测试场景 | 结论 | 已通过步骤 | 重大问题 |
|---|---|---|---|---|

| 2 | 默认伴侣与自然语言人设设置 | ✅ 通过 | 可自然聊天；一句话设置名字和表达偏好；刷新后仍记得 | 无重大问题 |
| 3 | 网页、微信、飞书跨渠道连续性 | ✅ 最新回归通过 | 真实微信、飞书均召回网页验证码及其网页来源；两端通过 Session 检索获得 `source=api_server` | 当前运行路径无重大问题；branded runtime 的共享 Session 路径仍有来源字段缺失风险 |
| 4 | 长对话、工具、Coding、压缩后人格连续 | ✅ 通过 | 搜索、读文件、Coding、手动压缩前后均保持“小河”及既定表达风格，没有退回通用助手身份 | 无重大问题 |
| 5 | 工具行动、审批与失败提示 | ✅ 最新回归通过 | 工具失败现在正确显示失败状态，折叠与展开卡片均不再误报“处理好了” | 无重大问题 |
| 6 | 一句话安装或配置能力 | ⚠️ 通过，但有重大问题 | 电影记录、周末提醒、第二次使用和停用均真实生效，不是只生成教程 | 首次配置约 88 秒、17 次模型调用；定时任务连续失败 15 次，且失败过程全部被显示为成功 |

| 10 | 记忆纠错、忘记与能力回滚 | ✅ 通过 | 纠错、定向遗忘、Skill 创建与回滚、伪密钥不入长期记忆全部成功，且无误删 | 无重大问题 |
